# radar-grapetec

Radar de preços da Grape Tec: menor preço postado por dia no canal [t.me/grape_tec](https://t.me/grape_tec).

- `site_data.json` — dados que a página [grapetec.com.br/live11-11](https://grapetec.com.br/live11-11) lê.
- `dados/` — base completa (posts classificados e menor preço por dia).
- `scripts/` — classificação, cálculo e geração do site.
